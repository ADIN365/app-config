Cari Mobil Saya — Kebijakan Privasi

LazyWorks (selanjutnya disebut ‘Pengembang’) menghargai privasi pengguna aplikasi Cari Mobil Saya (selanjutnya disebut ‘Aplikasi’) dan menyediakan kebijakan ini sesuai dengan Undang-Undang Perlindungan Informasi Pribadi Republik Korea.

1. Informasi pribadi yang dikumpulkan

Untuk menyediakan layanan, Aplikasi memproses informasi berikut hanya di perangkat Anda.

InformasiTujuanLokasi penyimpanan
Informasi lokasi (GPS)Menyimpan lokasi parkir secara otomatis dan menampilkannya di petaDatabase lokal di perangkat
Informasi perangkat Bluetooth (nama dan alamat MAC)Mencatat parkir secara otomatis dengan mendeteksi koneksi dan terputusnya Bluetooth mobilDatabase lokal di perangkat
Foto dari kameraMenyimpan foto lokasi parkir saat pengguna memilih untuk mengambil fotoPenyimpanan perangkat

2. Tujuan pengumpulan dan penggunaan

  • Mendeteksi dan menyimpan lokasi parkir secara otomatis
  • Menampilkan lokasi parkir di peta untuk membantu pengguna menemukan mobil
  • Mencatat lantai parkir dan foto
  • Menampilkan informasi parkir melalui widget di layar utama

3. Penyimpanan dan penghapusan data

  • Semua data hanya disimpan di perangkat pengguna dan tidak dikirim ke server eksternal.
  • Riwayat parkir dihapus secara otomatis setelah masa penyimpanan yang dipilih pengguna (7 hari hingga 1 tahun) berakhir.
  • Menghapus instalasi Aplikasi akan langsung menghapus semua data.

4. Layanan pihak ketiga

Aplikasi tidak memberikan informasi pribadi Anda kepada pihak ketiga. Namun, layanan berikut dapat mengumpulkan data sesuai dengan kebijakan privasi masing-masing.

  • Google AdMob — Mengumpulkan ID iklan untuk menayangkan iklan (Kebijakan Privasi Google)
  • Firebase Crashlytics — Mengumpulkan log kerusakan untuk menganalisis error aplikasi, tanpa informasi yang dapat mengidentifikasi pribadi
  • Firebase Analytics — Mengumpulkan statistik penggunaan anonim, seperti jenis sinyal Bluetooth dan waktu respons, tanpa informasi yang dapat mengidentifikasi pribadi
  • Google Play — Memproses pembelian dalam aplikasi untuk menghapus iklan

6. Hak pengguna

  • Anda dapat menghapus catatan parkir sendiri melalui setelan Aplikasi.
  • Anda dapat mengubah atau mencabut izin Aplikasi kapan saja melalui setelan perangkat.
  • Menghapus instalasi Aplikasi akan menghapus seluruh data yang tersimpan secara menyeluruh.
